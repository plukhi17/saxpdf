How to unlock a PDF

Use the SAXPDF workspace above to create an unprotected copy:

01. Select the password-protected PDF.

02. Enter the password you use to open it.

03. Process and download the unprotected copy.

Important: output format

This browser-based conversion renders each page into an image and places those images in a new, unprotected PDF. Page appearance is retained, but text will not be selectable or searchable, and links, forms, accessibility features, and other interactive PDF content are not preserved. Larger or image-heavy PDFs may take longer to process and create larger output files.

File and password privacy

The selected PDF and password are processed locally in your browser and are not intentionally uploaded to SAXPDF servers. The page loads PDF libraries from third-party CDNs and may use hosting or analytics services. See the Privacy Policy for more information.

Frequently asked questions

Can this tool unlock a PDF without its password?

No. You must provide a password that can open the PDF. This tool does not crack or bypass PDF passwords.

Will the output preserve selectable text?

No. To create the unprotected copy in the browser, this tool converts each page into an image. Text and other interactive PDF features are not preserved.

Are my PDF and password uploaded?

The tool is designed to process both in your browser and does not intentionally upload them to SAXPDF servers. The page still loads third-party libraries and the site may use hosting, analytics, or advertising services.
