How to split pdf

Use the SAXPDF workspace above to process your file in a few steps:

01. Select the PDF file you want to split.

02. Enter a page range such as 1-3 or 1,3,5.

03. Process the file and download the extracted pages.

About this tool

Extract a page or page range from a PDF and save it as a separate document with SAXPDF. The tool uses browser-based PDF libraries to process the selected files. Performance can depend on your browser, device memory, and file size.

File privacy

The current tool is designed to process selected files locally in your browser and does not intentionally upload document contents to SAXPDF servers. The site loads required third-party libraries and may use hosting, analytics, or advertising services. See the Privacy Policy for more information.

Frequently asked questions

How do I choose pages?

Enter page numbers or ranges such as 1-3 or 1,3,5 in the page-range field.

Does splitting change the original file?

No. The tool creates a separate output file; your original file remains on your device.

Can I split a large PDF?

It depends on your device memory and browser. Very large files may take longer to process.
