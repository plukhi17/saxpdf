How to merge pdf

Use the SAXPDF workspace above to process your file in a few steps:

01. Select two or more PDF files from your device.

02. Add files in the order you want them combined.

03. Select Merge and download the combined PDF.

About this tool

Combine multiple PDF files into one document with SAXPDF. Choose your files, arrange them in the order you want, and download one combined PDF. The tool uses browser-based PDF libraries to process the selected files. Performance can depend on your browser, device memory, and file size.

File privacy

The current tool is designed to process selected files locally in your browser and does not intentionally upload document contents to SAXPDF servers. The site loads required third-party libraries and may use hosting, analytics, or advertising services. See the Privacy Policy for more information.

Frequently asked questions

Can I merge more than two PDF files?

Yes. Select two or more PDF files. The merged document follows the order in which the files are added.

Are my PDF contents uploaded to SAXPDF?

The current tool is designed to process selected files in your browser and does not intentionally upload document contents to SAXPDF servers. The page still loads third-party libraries and the site may use hosting, analytics, or advertising services.

Can I use the merged PDF immediately?

When processing completes, use the download link shown in the workspace to save the new PDF.
