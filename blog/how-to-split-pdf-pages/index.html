How to split PDF pages into a new document

Splitting extracts selected pages into a smaller PDF while leaving the original document unchanged.

SAXPDF Editorial · 22 November 2026 · 4 min read

When to split a PDF

Split a PDF when you need to send only a section of a report, separate a signed page, archive selected invoices, or reduce the pages in an attachment. It is also useful when one long PDF contains several unrelated forms or chapters.

How to split PDF pages

  1. Choose the PDF. Open the SAXPDF Split PDF tool and select the source file.
  2. Enter the page range. Use the number of the first and last page you want, such as 1-3. Confirm that the range is within the document's page count.
  3. Split and download. Process the PDF and save the new file. Review it to ensure all selected pages appear in the correct order.

Tips for accurate page ranges

Page 1 is the first visual page, even if the printed page number is different. For a single page, enter just that number if the tool supports it. If the PDF has 20 pages and you need the middle section, a range such as 8-14 is clearer than a comma-separated list of every page.

Frequently asked questions

How do I split a PDF?

Choose the PDF, enter a valid range such as 1-3, process it, and download the result.

Will splitting change the original PDF?

No. Splitting creates a separate PDF containing selected pages.

Can I extract several ranges?

For more than one separate range, split the document into smaller groups or create separate result files as supported by the current tool.
